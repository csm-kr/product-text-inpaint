# 이미지 자글거림 정리와 원본 문자 복원

이 스킬은 `product-text-inpaint` 독립 저장소의 도구를 사용한다. 설치된 스킬의 `runtime.json`에서 실행 도구 위치를 읽거나, 저장소 안의 스킬이면 두 단계 위 저장소 루트를 찾는다. 도구가 없으면 공개 저장소 `https://github.com/csm-kr/product-text-inpaint`를 설치한다. 상세 설치·명령은 [references/workflow.md](references/workflow.md)를 읽는다.

## 모드 선택

- **원본 글자·로고 보존:** 실제 원본을 source, 구도·배경을 유지할 사진을 base로 받는다. 원본 정리에서는 같은 사진을 둘로 사용한다. base의 기존 글자를 지우고 원본 잉크만 마지막에 합성한다. 기본 선택이다.
- **AI 이미지 정리:** 글자 보존을 요구하지 않거나 사용자가 사진·문자 자체의 AI 편집을 요청한 경우, `cleanup`으로 선택 영역 또는 전체 이미지를 정리한다. AI가 해당 픽셀을 다시 그리므로 문자 내용·제품 동일성을 직접 비교한다.

이미지를 열어 실제 글자와 원하는 범위를 확인한다. 이미 지정한 크기·작업 방식을 다시 묻지 않는다. 글자가 있는 사진의 원본 보존 요청에는 잉크 복원을 우선한다. 원본 흐림·손상에서 없는 정보를 만들어 복원했다고 말하지 않는다.

## 실행 경로

저장소 내부에서는 `text-clean.cmd` / `./text-clean`을 사용한다. 다른 사진 폴더에서는 설치된 `scripts/run.py`가 설치 위치의 도구를 호출한다. 현재 작업 폴더를 유지하므로 상대 사진·출력 경로는 사진 폴더 기준이다. 도구를 별도 UI에서 열 필요가 없다.

런타임은 해당 설치의 `.venv` Python, 로컬 Node·FFmpeg를 사용한다. 없으면 `setup-local.cmd` / `setup-local.sh`로 준비한다. 각자 Codex에 로그인하며 인증 파일을 복사하지 않는다. Windows 명령은 `tty:true`, 백그라운드 자식은 창 숨김을 유지한다.

AI 호출 전에 현재 계정이 지원하는 모델을 확인해 `--model` 또는 프로세스의 `CODEX_IMAGEGEN_MODEL`로 지정한다. 사용자가 지정한 값을 존중한다. 전역 설정은 바꾸지 않는다. HTTP 400이면 오류 메시지를 읽어 원인을 고치며 같은 요청을 반복하지 않는다. 이 도구는 지원되지 않는 private backend를 사용한다.

## 원본 잉크 보존 절차

1. source·base를 열어 EXIF 회전 후 좌표를 확인한다. 원근·크기가 다르면 같은 인쇄면의 대응 모서리 네 개를 지정한다. OCR이나 유사 폰트로 다시 쓰지 않는다.
2. `layers prepare`로 정렬한 원본의 문자 마스크·RGBA 잉크를 만든다. 자동 추출은 균일한 밝은/유색 면 위 어두운 잉크에 적용한다. 유색 로고·사진 위 글자·반사면에는 검수한 수동 마스크를 사용한다.
3. `*-alpha.png`, `*-preview.png`를 100% 확인한다. 스크래치·먼지는 제외 영역이나 수동 마스크로 빼고 문장부호·악센트·가는 획은 보존한다. 이 검수는 에이전트가 수행하며 별도 사용자 승인 단계가 아니다.
4. 검수한 준비 폴더로 `restore`를 실행한다. 문자 박스를 순서대로 AI 인페인팅해 이전 글자를 지우고 원본 잉크를 마지막에 합성한다. 평평한 인쇄면은 detail level 1로 시작한다. 기존 결과를 덮어쓰지 않는다.
5. 글자가 남아 합성이 실패하면 배경 결과를 확인하고 새 폴더에서 재작업한다. 희미한 이전 획도 통과시키지 않는다. 좋은 인페인팅 결과가 이미 있으면 `layers composite`로 AI를 재호출하지 않는다.
6. 최종 PNG·100% 비교·마스크·좌표·검증 JSON을 남긴다. 인쇄 사진 등 복원하지 않은 영역과 잔여 질감을 검수 범위대로 설명한다.

## 완료 판정

- 지정 영역 밖 픽셀과 캔버스 크기를 유지한다. 전체 이미지 AI 정리에서는 보존할 영역 밖이 없음을 구분한다.
- 불투명 잉크 내부는 준비된 원본 잉크 레이어와 동일하다. 원근·크기 변환 후에는 원본 JPG의 바이트 동일성을 주장하지 않는다. 가장자리·문자 내용·마스크 적합성은 별도 시각 검수다.
- 원본 사각형 전체를 붙여 종이 노이즈를 되돌리지 않는다. 잉크에는 Poisson이나 가장자리 블러를 적용하지 않는다.
- 별도 요청 없이 노이즈 제거 필터·샤프닝·업스케일을 추가하지 않는다. 자글거림 완전 제거나 상업적 권리를 보장하지 않는다.

사용 예: `$product-text-inpaint 원본.jpg의 글자·로고를 유지하면서 인쇄면 자글거림만 정리해줘. source와 base는 같은 파일이야.`
